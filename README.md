# 我的塔罗 · iPhone 私人牌桌

这是一个静态 PWA 原型。核心逻辑：

- 78 张牌全部背面朝上，由用户自己点击选择，不自动随机抽取。
- 同一组抽牌不会重复。
- 选几张都可以（1–78 张）。
- 进入翻牌阶段后，每张牌单独翻开。
- 正位 / 逆位在翻牌时随机决定。
- 抽牌问题、备注和结果保存在浏览器 localStorage 中。
- 记录不上传服务器。
- 使用 Rider–Waite–Smith 1909 公版牌面图片的公开数据源。
- 牌背使用本项目自己的 CSS 设计，不复制商业牌组的牌背。

## 在 iPhone 上使用

需要把整个文件夹放到一个 HTTPS 静态网站上，例如 GitHub Pages、Netlify 或其他静态托管。

打开网站后，在 Safari：
分享 → 添加到主屏幕 → 名称改成「我的塔罗」。

注意：牌面图片来自外部公版数据源，因此第一次使用需要联网加载图片；抽牌记录本身保存在本机浏览器。
